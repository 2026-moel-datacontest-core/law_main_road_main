## 제품 및 서비스명

**법대로 AI(LawMainRoad)**

외국인 근로자와 정보 취약 근로자가 근로계약, 임금체불, 부당해고, 기숙사·사업장 변경 등 노동 문제를 한국 노동법 근거와 함께 정리하고 다음 행동을 준비하도록 돕는 **근거 기반 노동권 보호 AI 서비스**.

법대로 AI는 법률 자문, 행정기관 판단, 노무사·변호사의 개별 사건 검토를 대체하지 않는다. 서비스의 역할은 사용자가 상담·신고·구제신청 전에 사실관계, 관련 법령 근거, 증거 목록, 문서 작성안의 빈칸을 정리하도록 돕는 보조 도구이다. 실제 신고, 체류 관련 결정, 소송·구제신청 진행 여부는 반드시 고용노동관서, 노동위원회, 외국인근로자 지원기관 또는 전문가 확인을 거치도록 안내한다.

## 1) 제품 및 서비스의 목적, 기능 및 특징

### 목적 및 배경

근로계약서, 해고 통보, 임금체불, 사업장 변경 같은 노동 문제는 사용자가 법령과 행정 절차를 즉시 이해하기 어렵다. 특히 외국인 근로자, 사회초년생, 비정형 근로자, 장애인 근로자처럼 정보 접근성이 낮은 사용자는 문제가 생겨도 어느 기관에 무엇을 준비해야 하는지 판단하기 어렵다.

법대로 AI는 사용자의 상황을 일반 상담 문장으로만 처리하지 않고, 고용노동 관련 법령 코퍼스를 검색한 뒤 검색된 근거 안에서만 답변과 다음 행동을 제시한다. 사용자가 입력하지 않은 사실은 임의로 보충하지 않고 확인 필요 정보, 주의사항, 증거 체크리스트로 분리해 표시한다.

### 현재 구현 범위와 향후 계획 구분

| 구분 | 현재 구현 범위 | 향후 계획 |
| --- | --- | --- |
| Before | 계약서 이미지/PDF 또는 텍스트에서 임금, 근로시간, 휴일, 기숙사, 공제 등 위험 신호 확인 | 계약서 유형 확대, 다국어 OCR 품질 개선 |
| Bridge | 계약서 검토 결과를 이후 상담 질문의 맥락으로 연결. 법적 근거가 아니라 사건 배경 정보로만 사용 | 별도 화면 확장은 이용자 검증 후 결정 |
| After | 자유 서술 질문에 대해 법령 검색 기반 답변, 근거 인용, 주의사항, 증거 체크리스트 제공 | 다국어 설명, 기관 상담용 요약 리포트 |
| 백엔드 API 기반 실시간 문서 초안 생성 | 사용자가 입력한 사건 정보와 답변의 법령 근거를 바탕으로 임금체불 진정서, 부당해고 구제신청 이유서 작성안 생성 | 지원 문서 유형 확대 |
| 프론트엔드 고정 예시 화면 | 사업장 변경 사유 정리서는 사용자 입력만으로 정형화하기 어려워 화면 흐름 시연용 고정 예시로 분리. 실시간 생성 성능 주장에 포함하지 않음 | 실시간 생성 대상 포함 여부는 별도 검증 후 결정 |
| History | 로그인 사용자의 계약서 검토 기록과 상담 연결 기록 보관, 목록 숨김 처리 제공 | 파일럿 전 보관·삭제 운영 정책 확정 |

### 핵심 기능

- **근거 기반 노동법 답변**: PostgreSQL + pgvector 검색으로 관련 법령 조각을 찾고, 검색된 문맥에 기반해 답변과 인용 법령을 생성한다.
- **계약 전 위험 탐지(Before)**: 계약서/OCR 결과에서 임금, 근로시간, 휴일, 기숙사, 공제 등 핵심 항목의 누락·불명확·주의 필요 신호를 확인한다.
- **Before -> Bridge -> After 연결**: 계약 단계에서 발견된 위험을 이후 실제 분쟁 질문으로 이어 준다. Bridge는 맥락 연결용이며 법적 근거를 만들거나 바꾸지 않는다.
- **문서 작성안 생성**: 답변에서 확인된 법적 근거와 사용자의 사건 정보를 바탕으로 고용노동청 임금체불 진정서, 노동위원회 부당해고 구제신청 이유서 작성안을 생성한다.
- **불확실성 표시**: 사용자가 입력하지 않은 사실은 작성안의 빈칸과 확인 필요 항목으로 남겨 과도한 단정 답변을 줄인다.
- **개인정보 최소화**: 브라우저 저장소(localStorage/sessionStorage), 서버 저장, 원문 계약서 처리, 체류·국적 정보 입력 범위를 분리해 민감 사건정보 노출을 줄인다.

## 2) 제품 및 서비스의 고용노동 데이터 활용 방안

### 데이터 활용 원칙

심사 기준상 핵심은 "고용노동 공공데이터를 실제 서비스 판단 흐름에 어떻게 쓰는가"이다. 법대로 AI는 한국 고용노동 관련 법령 원문을 조문 단위로 전처리해 법령 검색·근거 인용·문서 작성안 생성에 직접 사용한다. 통계성 데이터는 개별 사건 판단 근거로 쓰지 않고, 문제 규모 설명, 파일럿 우선순위, 사업화 지표 설정에만 사용한다.

### 활용 데이터와 서비스 연결

현재 서비스의 답변 근거는 **국가법령정보센터 계열 법령 원문을 조문 단위로 전처리한 `1722`개 법령 조각**이다. 이 코퍼스는 법률·시행령·시행규칙을 조문 단위로 정규화하고 식별자, 인용 표시명, 출처, 조문 번호를 부여해 검색·인용·작성안 생성에 직접 사용한다.

공공데이터포털의 고용노동부 법령 데이터는 **법령명·조문명·조문 번호 기준으로 현재 코퍼스의 공식 데이터 항목 대조와 출처 관리에 활용**한다. 임금체불 통계, 외국인근로자 현황 통계 같은 통계성 데이터는 개별 사건 판단 근거가 아니라 문제 규모 설명, 파일럿 우선순위, 사업화 지표 설정에 사용한다.

| 데이터 영역 | 현재 활용 방식 | 경계 |
| --- | --- | --- |
| 고용노동부 고용노동 관련 법령 데이터 (근로기준법, 최저임금법, 산업안전보건법, 외국인근로자의 고용 등에 관한 법률, 남녀고용평등법, 산업재해보상보험법, 장애인고용촉진법 등) | 조문 단위 전처리 후 법령 검색·답변 근거 인용·문서 작성안 생성에 직접 사용. 코퍼스 항목 대조와 공식 출처 관리에 공공데이터포털 고용노동부 법령 데이터셋을 함께 활용 | 답변은 현재 코퍼스에 포함된 조문 근거 안에서만 생성 |
| 고용노동부 임금체불 현황 데이터 | 임금체불 문제 규모 설명, 상담 전 정리 도구의 공공성 설명, 사업화 지표 | 개별 사건 체불 여부 판단 근거로 사용하지 않음 |
| 고용노동부 지역·업종별 외국인근로자 현황 데이터 | 외국인근로자 지원기관 파일럿 지역·업종 우선순위 설정 | 개인별 위험 점수나 체류 판단에 사용하지 않음 |

코퍼스에 포함된 주요 모법은 근로기준법, 최저임금법, 산업안전보건법, 근로자퇴직급여 보장법, 외국인근로자의 고용 등에 관한 법률, 남녀고용평등과 일·가정 양립 지원에 관한 법률, 산업재해보상보험법, 장애인고용촉진 및 직업재활법 등이다.

### 추가 연계 검토 데이터

| 데이터 영역 | 활용 방향 | 유의점 |
| --- | --- | --- |
| 한국고용정보원 워크넷 채용정보 | 사업장 변경·재취업 단계 일자리 탐색 연계 검토 | 활용신청, 이용허락, 제3자 권리 조건 확인 후 적용 |
| 근로복지공단 임금체불 대지급금 현황 | 체불 임금 구제 경로 안내, 정책 효과 분석 보조 | 서비스 답변의 법적 판단 근거가 아니라 통계·제도 설명 용도 |

### 데이터 가공 방식

1. 법령 원문을 기준일 기준 유효 스냅샷으로 선택한다.
2. 법률·시행령·시행규칙을 조문 단위로 정규화한다.
3. 조문별 식별자, 인용 표시명, 출처, 소관 부처, 법령 번호, 조문 번호를 부여한다.
4. 검색용 문장을 생성해 `gemini-embedding-001`로 임베딩한다.
5. PostgreSQL + pgvector에 저장하고 HNSW 기반 검색으로 질문과 관련된 조문을 찾는다.
6. 답변과 문서 작성안은 검색된 근거와 인용 법령 안에서만 생성한다.

### 출처 관리

법령 원문 출처와 공공데이터포털에서 대조에 사용한 데이터셋의 식별 정보, 데이터셋명, 갱신일자, URL은 별도 출처 관리 노트에서 최신 기준으로 유지한다. 본문에는 데이터셋 ID와 일자 코드를 단정 표기하지 않고, 공모전 제출 시점에 확인한 최신 정보를 참고자료에 정리해 함께 제출한다.

| 생성형 AI | 답변, 요약, 구조화 | 자연어 사건 설명을 요약·구조화 | 주의사항과 확인 필요 정보로 단정 방지 |
| 규칙 기반 문서 작성 | 문서 작성안 | 답변에서 확인된 법령 근거와 사용자의 사건 정보를 이용해 작성안 생성 | 인용 법령과 검색 근거가 없으면 작성안 생성 차단 |
| 규칙 기반 검증 | 계약서 위험 판단 보조 | 최저임금, 근로시간, 필수 항목 등 계산·검증 | 계산·필수항목 검토를 LLM에만 맡기지 않음 |

### AI 활용 흐름

```
사용자 질문/계약서 입력
  -> OCR 또는 텍스트 구조화
  -> 질문 임베딩
  -> pgvector HNSW retrieval
  -> 관련 법령 조문 검색
  -> 근거 기반 답변 생성
  -> 법령 인용 / 주의사항 / 증거 체크리스트
  -> 지원 문서 작성안 생성
```

### 환각 방지 및 신뢰성 설계

- 법률 답변은 검색된 법령 조문 안에서만 인용을 만든다.
- 검색 결과에 없는 조문을 답변의 근거처럼 추가하지 않는다.
- 인용 법령과 검색 근거가 비어 있으면 문서 작성안 흐름을 열지 않는다.
- Bridge는 사건 맥락 연결용으로만 사용하며, 법적 근거를 새로 만들거나 바꾸지 않는다.
- 문서 작성안 생성 API는 법령 검색이나 답변 생성을 다시 호출하지 않고, 이미 생성된 답변의 법령 근거만 사용한다.
- 사업장 변경 사유 정리서는 사용자 입력만으로 정형화하기 어려워 화면 흐름 시연용 고정 예시로 분리하며, 백엔드 API 기반 실시간 문서 생성 성능 주장에 포함하지 않는다.

### 현재 검증 기준과 평가 방법

검색 평가 지표 정의:

- **hit@1**: 첫 번째 검색 결과가 기대 법령 근거에 해당하는 비율
- **hit@3**: 상위 3개 검색 결과 안에 기대 법령 근거가 포함된 비율
- **hit@5**: 상위 5개 검색 결과 안에 기대 법령 근거가 포함된 비율

| 평가 항목 | 결과 | 해석 |
| --- | --- | --- |
| 시나리오 수 | `60`건 | 임금체불, 해고, 계약 조건, 기숙사·공제, 사업장 변경 등 노동 문제 범위 |
| 법령 검색 hit@1 | `51/60` | 첫 번째 검색 결과가 기대 법령 근거에 도달 |
| 법령 검색 hit@3 | `59/60` | 상위 3개 검색 결과 내 기대 근거 도달 |
| 법령 검색 hit@5 | `60/60` | 상위 5개 검색 결과 내 기대 근거 도달 |
| 응답 생성 | `60/60` | 응답 생성 실패 없이 답변 생성 |
| 근거 검토 | `PASS=44`, `PARTIAL=16`, `FAIL=0` | 인용 법령과 답변 근거의 품질 검토 결과 |

본 평가는 **자체 60건 시나리오셋 기반의 기준선이며 외부 표준 벤치마크가 아니다.** 평가 목적은 현재 법령 코퍼스와 공모전 검증 시나리오 안에서 검색 정확도와 근거 준수 여부를 확인하는 것이다. 답변에 표시된 법령 근거가 실제 검색된 법령 조문 안에 존재하는지 확인하며, 프론트엔드 고정 예시 화면은 위 검색·답변 수치의 성능 근거로 사용하지 않는다. 자유 입력 경로는 실제 답변 API 호출 결과로 확인한다.

## 4) 창업 및 사업 계획

### 현재 단계

팀은 단순 아이디어 단계가 아니라 동작 가능한 서비스를 구현했다. 현재 구현 범위는 Next.js 기반 화면, FastAPI 백엔드, PostgreSQL + pgvector 법령 검색, Vertex AI Gemini 기반 답변·OCR·임베딩 연동, Firebase Auth, 백엔드 API 기반 실시간 문서 작성안 생성, 계약서 검토와 상담 기록 흐름까지 포함한다.

사업화의 1차 시장은 **외국인근로자 지원기관용 상담 전 정리 도구**로 좁힌다. 이유는 외국인 근로자 상담은 근로계약, 임금체불, 기숙사, 사업장 변경, 체류 관련 불안이 함께 얽혀 상담 전 사실관계 정리에 시간이 많이 들고, 기관 상담자는 사건별 증거와 관련 법령을 빠르게 구조화할 필요가 있기 때문이다.

### 1차 고객과 파일럿 계획

| 기간 | 목표 | 실행 내용 | 측정 지표 |
| --- | --- | --- | --- |
| 0~3개월 | 공모전 제출 및 검증용 데모 | Google Cloud 기반 공모전 검증용 환경을 구성하여 외부 접속 URL, QR, 핵심 화면 캡처, 3~5분 시연 영상을 제공 | 데모 성공률, 화면별 제출 증빙 완성 |
| 3~6개월 | 외국인근로자 지원기관 파일럿 | 외국인노동자지원센터, 지역 외국인주민 통합지원센터, 대학 노동상담센터, 노무 상담기관 등 후보군 중 2곳과 제한 파일럿. 상담 전 정리 케이스 50건 목표. 현재 단계는 MOU 체결이 아니라 협력 의사 타진 후보군이다. | 상담 전 사실관계 정리 시간 20% 단축, 작성안 완료율, 상담자 만족도 |
| 6~12개월 | 기관용 서비스 | 기관 계정, 상담 전 요약, 증거 체크리스트, 문서 작성안 묶음, 사용량 리포트 제공 | 기관 사용자 20명, 월 100건 상담 전 정리, 재사용률 |
| 12개월 이후 | 확장 검토 | 다국어 안내, 워크넷/Work24 연계, 외부 연동·기관 맞춤형 제공 검토 | 유료 전환 기관 수, 월 반복 매출, 데이터 갱신 준수율 |

"상담 전 사실관계 정리 시간 20% 단축"은 다음 방식으로 측정한다 (가설 단계 측정 설계).

- 파일럿 도입 전: 기관에서 동일 사건 유형 10건의 상담 전 사실관계 정리 시간을 baseline으로 측정
- 파일럿 도입 후: 동일 유형 10건에 대해 법대로 AI를 사용한 정리 시간을 비교
- 측정 도구: 상담자 self-report 설문과 실제 작성 시간 로그를 함께 사용

### 수익모델

| 모델 | 설명 | 가설 단가 | 초기 적용 가능성 |
| --- | --- | --- | --- |
| 기관 SaaS | 상담기관 좌석 단위 과금. 상담 전 요약, 증거 체크리스트, 기록 관리, 보안 경계를 제공 | 기관당 월 30만~50만원 또는 좌석당 월 3만~5만원 가설 | 1차 수익 모델 |
| 문서 작성안 묶음 | 임금체불 진정서, 부당해고 이유서 등 지원 문서 유형별 작성안 생성 기능을 기관용으로 제공 | 모듈별 추가 과금 가설 | 파일럿 검증 후 유료 기능화 |

Bottom-up 매출 가설: 파일럿 2곳 검증 이후 1년 내 10개 기관 전환을 가정하면 기관당 월 30만~50만원 기준 월 300만~500만원 반복 매출 수준이다. 가설 단계의 추정이며 실제 단가는 기관 보안 요구사항, 좌석 수, 도입 범위에 따라 재산정한다.

기관 보안 요구사항 대응, 외부 연동, 일반 이용자 유료화는 초기 계획서에서 과하게 확장하지 않고 파일럿 검증 이후의 선택지로 둔다.

### 운영 원칙

- 법률 자문 대체가 아닌 상담 준비·문서 작성안·근거 확인 도구로 제공한다.
- 실제 신고, 소송, 체류 관련 결정은 공공기관 또는 전문가 확인을 안내한다.
- 외국인 체류자격, 국적, 사업장명 등 민감하게 결합될 수 있는 정보는 기능상 필요한 경우에만 최소 입력한다.
- 파일럿은 실제 사건 원문보다 비식별 샘플·상담 전 요약 중심으로 운영하고, 정식 서비스 공개 전 별도 보안·개인정보 검토를 수행한다.

## 5) 기존 서비스 대비 차별성

| 구분 | 일반 생성형 AI 챗봇 | 법제처 찾기쉬운 생활법령정보 | 고용노동부 상담/민원 포털 또는 챗봇류 | 법대로 AI |
| --- | --- | --- | --- | --- |
| 사용자 입력 | 자유 질문 | 키워드/주제 검색 | 정형 민원 양식 또는 일반 질의응답 | 계약서/OCR + 자유 진술 + 사건 정보 입력 |
| 근거 제시 | 근거 안정성 보장 어려움 | 법령 원문 중심, 사용자 사건 맞춤 답변은 별도 | 절차·민원 처리 중심 | 검색된 조문 기반 근거 인용 |
| 계약 전후 연결 | 없음 | 없음 | 없음 | Before -> Bridge -> After 연결 |
| 취약 근로자 UX | 일반적 | 난이도 높음 | 절차 부담 | 한국어 요약, 확인 필요 정보, 증거 체크리스트 |
| 문서 작성안 | 가능하나 근거 확인 어려움 | 없음 | 양식 안내 중심, 사용자가 직접 작성 | 답변의 법령 근거를 바탕으로 작성안 생성 |
| 개인정보 경계 | 서비스별 상이 | 낮은 입력 민감도 | 민원 정보 직접 입력 | 브라우저 저장소(localStorage/sessionStorage) 저장 최소화, 로그인 기록 보호, 삭제 요청 흐름 명시 |
| 사업화 방향 | 범용 | 공공 정보 제공 | 행정 처리 | 외국인근로자 지원기관용 상담 전 정리 도구 |

비교 목적은 **차이를 설명**하는 것이며 각 기관 서비스의 가치를 평가하는 것이 아니다. 각 서비스는 본래 목적과 사용자 층이 다르며, 법대로 AI는 외국인 근로자·취약 근로자가 상담·신고 전에 사실관계와 근거를 정리하는 흐름에 특화되어 있다.

핵심 차별성은 "답변을 잘하는 챗봇"이 아니라 상담 전 준비 업무를 줄이는 흐름이다. 계약서 위험 신호, 관련 법령, 누락 사실, 증거 목록, 문서 작성안을 한 번의 사용자 여정으로 연결해 상담기관이 다음 질문을 더 빠르게 할 수 있도록 돕는다.

| 보관기간 | 공모전 데모는 샘플 데이터만 사용한다. 파일럿은 기본 30일 보관 후 삭제 또는 연장 동의 방식으로 설계 | 파일럿 전 물리 삭제·계정 삭제 정책을 운영 정책으로 확정 |
| 삭제 방식 | 사용자가 기록 목록에서 삭제 요청을 할 수 있고, 삭제된 기록은 일반 사용자 화면과 연결 흐름에서 제외 | 정식 서비스 운영 전 삭제 요청 처리 절차와 관리자 책임 범위 명시 |
| 원문 계약서 | 브라우저 저장소에 원문 계약서를 저장하지 않고, 화면에는 필요한 요약과 위험 신호 중심으로 표시 | OCR 파일 업로드 보관 여부, 임시 파일 삭제 주기 명시 필요 |
| 외국인 체류·국적 정보 | 체류자격, 국적, 사업장명은 기능상 필요한 경우에만 최소 입력. 권리 안내와 체류 판단을 분리 | 체류 관련 결정은 출입국·노동 전문기관 확인 안내 필수 |
| 민감 사건정보 | 임금체불, 해고, 차별, 장애, 건강, 노조 관련 정보가 결합될 수 있음을 전제로 최소 수집 | 파일럿 전 개인정보 영향 검토와 비식별 샘플 사용 원칙 강화 |

데모 영상과 화면 캡처에는 샘플 데이터만 사용한다. 이메일, 인증 토큰, 내부 URL, API key, 실제 사건 원문은 노출하지 않는다.

### 법률 자문 오인 방지 문구

서비스 화면과 문서 작성안에는 다음 취지의 문구를 반복 노출한다.

> 이 결과는 법률 자문이나 행정기관의 판단을 대체하지 않습니다. 실제 신고, 구제신청, 소송, 체류 관련 결정 전에는 고용노동관서, 노동위원회, 외국인근로자 지원기관 또는 전문가 확인을 받으십시오.
>

### 외국인 근로자 보호 관점

- 사업장 변경, 기숙사, 공제, 체류 불안처럼 민감한 사안은 단정적 결론보다 "확인할 사실", "준비할 증거", "상담기관에 물어볼 질문" 중심으로 제시한다.
- 국적·체류자격을 입력받는 경우에는 답변 품질에 필요한 최소 범위와 사용 목적을 화면에서 설명한다.
- 체류자격 판단, 강제퇴거 위험, 출입국 절차는 서비스가 판단하지 않고 관계 기관 확인 대상으로 분리한다.
